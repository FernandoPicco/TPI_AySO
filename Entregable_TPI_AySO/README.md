# Trabajo Práctico Integrador – Arquitectura y Sistemas Operativos (AySO)

Este repositorio contiene el Trabajo Práctico Integrador de la materia AySO, realizado en el entorno de una Máquina Virtual Ubuntu y acompañado por el desarrollo de un script en Python para la gestión de notas de alumnos.

Su organización permite que cualquier docente, revisor o compañero pueda navegar el proyecto de forma rápida y comprender su funcionamiento sin necesidad de configuraciones complejas.

---

## 📁 Estructura del repositorio

La carpeta **/entregable** incluye todo el material digital solicitado para la entrega final:

- **Trabajo Práctico Integrador_AySO.pdf**  
  Documento técnico completo: instalación del entorno, configuración de la VM, comandos utilizados, análisis, conclusiones y resultados.

- **Capturas_TPI_Virtual_Box.pdf**  
  Evidencia visual de todo el proceso: instalación, configuración y pruebas realizadas.

- **notas_alumnos.py**  
  Script en Python que calcula el promedio de varios alumnos, muestra estadísticas simples y permite repetir la carga.

- **README.md**  
  Archivo explicativo del contenido del repositorio.

---

## ▶️ Ejecución del script de Python

El archivo `notas_alumnos.py` funciona desde cualquier entorno con Python instalado.

### **1. Requisitos**
- Python 3.x  
- No requiere librerías adicionales

### **2. Cómo ejecutarlo**

Abrir una terminal y ejecutar:

```bash
python3 notas_alumnos.py
---
El programa permitirá:

- Ingresar varios alumnos

- Cargar tres notas por alumno

- Calcular su promedio

- Mostrar cuántos aprobaron y desaprobaron

- Repetir carga si el usuario lo desea
